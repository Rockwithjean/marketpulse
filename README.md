# MarketPulse Landing Page

A polished fintech-style marketing landing page for a Deriv trading bot business.

## Files
- `index.html` — main landing page
- `styles.css` — visual design and responsive layout
- `script.js` — small script for dynamic footer year
- `view-code.html` — quick code view page

## Run locally
Open `index.html` directly in a browser, or serve the folder with a local HTTP server:

```bash
cd "C:\Users\Imelda Ntinyari\kenyan-prince-clone"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```
